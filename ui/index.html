Guide

New here? Start at the top and go down. Each step is short. Click a title to open it.

1Make your first video 2 minutes
  1. Open the Create page (left side).
  2. Click a style card, for example Math & Puzzles. A form opens below the cards.
  3. Leave the settings as they are and press Generate.
  4. Watch the Queue on the right. A video takes about 1 to 3 minutes.
  5. When it says Finished, open Library and click the video to play it. The file is also in the output folder of the app.

The first time, the app may ask you to download the voice files (about 340 MB). Open Settings and press Download voice files. It is one time only.

2What each style does
  • Math & Puzzles - word problems and riddles with a voice, drawings and the working-out shown step by step.
  • Satisfying Balls - calming physics videos (balls, bricks, pegs) with satisfying sounds. Great for ASMR channels.
  • Music Balls - balls play a famous public-domain song on a xylophone, bells, glass or drums.
  • Story & Facts - you type topics, the AI writes the script, a voice reads it. Needs Ollama (see Settings).
  • From a reference link - paste a link to a video you like. The app studies its style and makes a new, original video.
3Turn on the AI (optional) needed for Story & reference
  1. Install Ollama from ollama.com and open it once.
  2. In this app open Settings. Under Download a model leave llama3.2:3b and press Download. It takes a while (about 2 GB).
  3. When it finishes, choose it under Model and press Save.
4Post your videos automatically Facebook + Instagram

This part needs a few accounts and keys. Do the steps below once, in order. You will copy a few IDs and tokens into the Publish page. Nobody else sees them - they stay on this computer.

What you need first: an Instagram Professional account (Business or Creator), a Facebook Page you manage, and a free GitHub account.

4aInstagram: get the token and ID
  1. Make sure your Instagram is a Professional account: Instagram app → Settings → Account type and tools → switch to professional (Creator or Business).
  2. Go to developers.facebook.com and log in with your Facebook.
  3. Click My Apps → Create App. Choose the use case Manage messaging & content on Instagram (or Other → Business). Give it any name.
  4. In the app, open Instagram → API setup with Instagram login.
  5. Open App roles → Roles → Add People → choose Instagram Tester and type your Instagram username.
  6. Accept the invite in the Instagram app: Settings → Apps and websites → Tester invites. (This is the step most people miss.)
  7. Back on the API setup page, add the permission instagram_business_content_publish (under Permissions and features).
  8. On the API setup page click Add account, log in to your Instagram, then Generate token. Copy the token and the Instagram account ID.
  9. In this app: Publish → paste them into Instagram user ID and Instagram token → Save.

The token lasts about 60 days. The server script refreshes it automatically.

4bFacebook: get the Page ID and a token that never expires
  1. On developers.facebook.com open your app (or make a second one the same way). Add the use case Manage everything on your Page.
  2. Under that use case, open Permissions and features and add: pages_show_list, pages_manage_posts, pages_read_engagement.
  3. Open Tools → Graph API Explorer. Pick your app. Leave User or Page on User Token.
  4. Under Permissions add the same three permissions and press Generate Access Token. Approve the pop-ups and choose your Page.
  5. In the request box type me/accounts?fields=id,name and press Submit. Find your Page's name and copy its id. That is the Page ID.
  6. Copy the long token from the Access Token box (this is the short-lived User token).
  7. In your app on developers.facebook.com open App settings → Basic. Copy the App ID. Click Show next to App secret and copy it.
  8. In this app: Publish → type the Facebook Page ID and press Save. Then open Make my Facebook token permanent, paste the App ID, App secret and the User token, and press the button.

When it works you will see your Page name and "never expires". The app secret and user token are not stored.

4cGitHub: a place to host your videos for Instagram

Instagram downloads each video from a normal web link. A free public GitHub repository gives you that.

  1. Go to github.com → New repository. Name it something like my-media, choose Public, tick Add a README, press Create.
  2. Click your profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Pick Only select repositories and choose your new repo. Under Permissions → Repository permissions set Contents to Read and write. Generate and copy the token.
  4. In this app: Publish → GitHub repo = yourname/my-media, GitHub token = the token → Save.

Videos stay in the repo only until you remove them. Anyone can see a public repo, but these are videos you are posting publicly anyway.

4dMake a plan and schedule it
  1. Open Publish. Check the three tags at the top say ready.
  2. Under Post times keep the list or change it (24-hour clock, separated by commas).
  3. Choose Posts per day and Days, then press Preview plan. Read the list.
  4. Press Schedule on Facebook + publish plan. The app uploads the videos, schedules Facebook, and publishes the plan for Instagram. Watch the Queue.
  5. Press Check posts later to see that everything matches.

Facebook posts are scheduled by Facebook itself, so your computer can be off. Instagram has no scheduling, so a small script on a server posts it at the right time (next step).

4eInstagram posting on a server (VPS) step by step

Instagram has no "schedule" feature for apps, so a small script posts each reel at its time. It must run on a computer that is always on. That is what a VPS is: a small computer you rent. You do this once.

You need: a VPS (Windows or Linux) with a login, your Instagram user ID and token (from step 4a), and a plan already published from the Publish page (step 4d).

A. Get the files ready on your own computer

  1. Open Publish and press Download VPS package. A file vps-poster.zip is saved.
  2. Unzip it. You will see three files: vps_poster.py, .env.template and README.txt.

B. Connect to the VPS

  • Windows VPS: on your computer press the Windows key, type Remote Desktop Connection, open it, enter the VPS address, then the user name and password your provider gave you.
  • Linux VPS: open a terminal and run ssh user@VPS-ADDRESS.

C. Windows VPS

  1. Copy the unzipped folder on your computer (Ctrl+C), click inside the Remote Desktop window and paste it (Ctrl+V) on the VPS desktop. Then move it to C:\poster.
  2. On the VPS press the Windows key, type PowerShell, right-click it and choose Run as administrator.
  3. Check Python: 
    python --version
    If it says "not recognized", install it, then close PowerShell and open it again as administrator: 
    Invoke-WebRequest https://www.python.org/ftp/python/3.11.9/python-3.11.9-amd64.exe -OutFile $env:TEMP\py.exe
Start-Process $env:TEMP\py.exe -ArgumentList '/quiet InstallAllUsers=1 PrependPath=1' -Wait
  4. Install the one library:
    cd C:\poster
python -m pip install requests
  5. Create your settings file. This opens Notepad; click Yes to create it, type the two lines, save and close:
    notepad C:\poster\.env
    IG_USER_ID=your instagram id
IG_TOKEN=your instagram token
  6. Check that the token works from the VPS. It should print your Instagram username: 
    python -c "import requests;e=dict(l.split('=',1) for l in open('.env',encoding='utf-8-sig').read().splitlines() if '=' in l);print(requests.get('https://graph.instagram.com/v21.0/me',params={'fields':'username','access_token':e['IG_TOKEN']}).json())"
  7. Test the poster. It should print started (dry run):
    python vps_poster.py --dry
  8. Make it start by itself, and also after a restart: 
    $py = (Get-Command python).Source
$a = New-ScheduledTaskAction -Execute $py -Argument "C:\poster\vps_poster.py" -WorkingDirectory "C:\poster"
$t = New-ScheduledTaskTrigger -AtStartup
Register-ScheduledTask -TaskName Poster -Action $a -Trigger $t -RunLevel Highest -User "SYSTEM" -Force
Start-ScheduledTask -TaskName Poster
  9. Confirm it is running:
    Get-ScheduledTask Poster | Select State
Get-Content C:\poster\vps_poster.log -Tail 5
    You should see Running and a line saying started.

C. Linux VPS (instead of the Windows steps)

  1. Copy the folder: scp -r vps-poster user@VPS-ADDRESS:~/poster (run on your computer).
  2. On the VPS:
    cd ~/poster
python3 -m pip install --user requests
printf 'IG_USER_ID=your id\nIG_TOKEN=your token\n' > .env
chmod 600 .env
python3 vps_poster.py --dry
nohup python3 vps_poster.py > /dev/null 2>&1 &

D. What to expect

  • The script reads your plan from your GitHub repo by itself, and picks up a new plan within a minute. You do not copy anything again.
  • About 10 minutes before each post time it prepares the reel (the log says #1 prepared). At the post time it publishes (#1 PUBLISHED).
  • If the VPS was off, it posts up to 2 hours late, otherwise it skips that slot and says so in the log.
  • Every ~30 days it refreshes your Instagram token on its own.
  • Look at vps_poster.log any time to see what it did.

E. If it does not work

  • "python is not recognized" - install Python (step C3), then reopen PowerShell.
  • The token check prints an error - the ID or token in .env is wrong or has extra spaces. Open it again and fix it.
  • The task state is not "Running" - run (Get-Command python).Source. If the path is inside your user folder (AppData), install Python for all users (step C3) and register the task again.
  • The log says container failed - the video link must be public: check your GitHub repo is Public.
5YouTube: schedule your videos same times as Facebook + Instagram

YouTube does not let apps upload and schedule new videos freely (a new Google project gets its uploads locked as private). The reliable way is: you upload the videos as Private in YouTube Studio, the app then writes the title, description and publish time of each one.

What you need: a YouTube channel and a Google account. It is free. Do 5a once, then 5b whenever you have new videos.

5a. One-time setup (about 10 minutes)

  1. Go to console.cloud.google.com and sign in with the Google account that owns your YouTube channel.
  2. Top bar → project picker → New project. Name it anything (for example my-youtube) → Create. Make sure it is selected.
  3. Left menu → APIs & Services → Library. Search YouTube Data API v3 → Enable.
  4. APIs & Services → OAuth consent screen (also called Google Auth platform). Press Get started. App name: anything. User support email and contact email: yours. Audience: External. Agree → Create.
  5. Open Audience. Under Test users press Add users and add your own Gmail address. Then press Publish app (so the sign-in does not expire after 7 days). If Google shows a warning, confirm.
  6. Open Clients (or Credentials → Create credentials → OAuth client ID). Application type: Desktop app. Name: anything → Create.
  7. Copy the Client ID and the Client secret.
  8. In this app: Publish → YouTube panel → paste both → Save → Sign in with Google. A browser tab opens. Choose your channel account. If it says Google hasn't verified this app, press Advanced → Go to (your app name) → Continue, tick the YouTube permission and continue.
  9. The panel now shows Signed in with your channel name.

If Google says Access blocked or 403 access_denied, your Gmail is not in the Test users list (step 4). Add it and try again.

5b. For each batch of videos

  1. In this app press Library → Open folder. Your videos are there.
  2. Open studio.youtube.com → Create → Upload videos. Drag the files in. Choose visibility Private (not Public, not Unlisted). Say No, it's not made for kids. Press Save.
  3. Wait until the videos finish processing in Studio.
  4. In this app: Publish → YouTube → choose Posts per day → Preview YouTube schedule. Read the list.
  5. Press Schedule on YouTube. Watch the Queue. Each video gets its title, description, tags and publish time. YouTube then publishes them by itself, even when this computer is off.
  6. Videos that are already in your Facebook/Instagram plan get the same time; the others continue after it.

Daily upload limit: YouTube Studio only accepts a limited number of uploads per day. If it says you reached the limit, upload the rest the next day and press Schedule on YouTube again. Only videos that are still Private and unscheduled are touched.

?If something goes wrong
  • "Voice model missing" - Settings → Download voice files.
  • "Ollama is not running" - open the Ollama app, then try again.
  • Facebook says the token expired - repeat 4b (the permanent token button).
  • Instagram says ERROR - the video link must be public. Check the GitHub repo is Public and the GitHub token has Contents: Read and write.
  • YouTube says quota or limit - wait a day and press Schedule on YouTube again. Already scheduled videos are not touched.
  • Nothing posts on Instagram - check the VPS script is running and read vps_poster.log. The VPS must be on.
  • The app looks old - Settings → Check now. Updates keep your videos and settings.
